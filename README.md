# python-bootcamp-team07
Welcome to the Python Bootcamp repository.
## Setup
1. Requirements
   - Python 3.10.
   - Git.
## Rules
To keep this repository consistent and easy to collaborate on, follow these rules:
1. Branching
   - Create feature branches from the default branch (e.g: 'main') with the following description: py/w1-github-username.
2. Commit messages
   - Do one exercise at a time. Commit after each exercise, with messages like feat(py-w1): W1-2 word counter.
3. Tests
   - Run the tests for your folder(e.g: $ pytest -q python-bootcamp/tests/test_w1.py --member github-username --variant 1).
4. Issues:
   - Each member opens one issue for their homework using the template that create with named: Python homework and set labels and milestone of each week.
6. Pull requests
   - Open a PR titled py-w1: github-username.
   - Link your issue that created.
   - Request your rotation reviewer.
   - When you review the PR you were assigned:
      + Do the instructor's tests pass in CI?
      + Is the code Pythonic (loops over items, comprehensions, f-strings) — or C++ written in Python syntax?
      + Are edge cases handled (empty input, wrong types, zero)?
      + Are names clear and are there docstrings?
      + Leave at least one Question, one Suggestion and one Praise.
      + Approve only after the tests pass and you understand the code.
7. Update PROGRESS.md:
   - Merge after approval. Update your row in PROGRESS.md in the same PR or a follow-up.
9. Week completed:
   - The leader pushes (e.g: tag py-w1-done).
